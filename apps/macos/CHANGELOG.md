# macos

## 1.4.0

### Minor Changes

- 1db40b9: 原稿用紙をイメージしたマス目や、ノートのような罫線を表示して文章を書けるようになりました。設定の「ガイド」にて表示を切り替えられます。
  あわせて、文章を印刷できる機能を追加したほか、行の先頭の番号を段落か行を示すか選べるようにしたり、原稿用紙に換算した枚数をステータスバーに表示できる機能を追加しました。
  
  You can now write on a grid inspired by Japanese manuscript paper, or on ruled lines like those in a notebook. Use Guide in Settings to switch between them.
  This update also adds printing, a choice of numbering paragraphs or lines, and an option to show in the status bar how many pages of manuscript paper your writing would fill.

## 1.3.0

縦書きで書けるようになりました。設定の「組方向」で、横書きと縦書きを切り替えられます。  
あわせて、細かな不具合を修正しました。

You can now write vertically. Use Orientation in Settings to switch between Horizontal and Vertical.  
This update also includes minor bug fixes.

## 1.2.0

Markdownファイル（拡張子 .md, .markdown, .mdx）を編集できるようになりました。  
Markdownの記法やHTML要素だと解釈できる文字は、字下げの対象から外し、色やウェイト、書体を変えて表示し、文章の構造がわかりやすくなります。もしこの仕様が執筆の集中の妨げになる場合は、設定の「Markdownの記法を強調する」オプションをオフにしてください。  
あわせて、オプション「読みやすい幅で折り返す」が有効かつウィンドウがアクティブでないときに、両端揃えで表示していた仕様を削除しました。

You can now edit Markdown files (.md, .markdown, and .mdx).  
Markdown syntax and HTML tags appear in a different color, weight, or typeface so the structure of your writing is easier to see, and paragraphs that begin with them aren't indented. If you find this distracting, turn off Highlight Markdown Syntax in Settings.  
Also, when Wrap to Readable Width is on, lines in inactive windows are no longer justified.

## 1.1.0

検索と置換の機能を追加しました。  
また、オプション「読みやすい幅で折り返す」が有効なときは、入力中は両端が揃わなくても字間を変えないようにすることで、執筆に集中できるようにしました。

You can now find and replace text.  
Also, when Wrap to Readable Width is on, lines are no longer justified while you type, so the spacing between characters stays steady and you can stay focused on your writing.
