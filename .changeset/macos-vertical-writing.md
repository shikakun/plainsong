縦書きで書けるようになりました。設定の「組方向」で、横書きと縦書きを切り替えられます。  
あわせて、メニューバーのみにアイコンを表示する設定でも、Dockにアイコンが表示されてしまう不具合を修正しました。

You can now write in vertical text. Set Orientation to Horizontal or Vertical in Settings.  
Also, Plainsong no longer appears in the Dock when Icon is set to Show in Menu Bar.
