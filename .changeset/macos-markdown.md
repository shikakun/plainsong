Markdownファイル（拡張子 .md, .markdown, .mdx）を編集できるようになりました。  
Markdownの記法やHTML要素だと解釈できる文字は、字下げの対象から外し、色やウェイト、書体を変えて表示し、文章の構造がわかりやすくなります。もしこの仕様が執筆の集中の妨げになる場合は、設定の「Markdownの記法を強調する」オプションをオフにしてください。  
あわせて、オプション「読みやすい幅で折り返す」が有効かつウィンドウがアクティブでないときに、両端揃えで表示していた仕様を削除しました。

You can now edit Markdown files (.md, .markdown, and .mdx).  
Text recognized as Markdown syntax or HTML elements isn't indented, and is shown in a different color, weight, or typeface, so the structure of your writing is easier to see. If this gets in the way of focusing on your writing, turn off the “Highlight Markdown Syntax” option in Settings.  
Also, when Wrap to Readable Width is on, lines are no longer justified in windows that aren't active.
